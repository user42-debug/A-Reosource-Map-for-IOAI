# A-Reosource-Map-for-IOAI
A curated path through the official IOAI syllabus  from Python basics to diffusion models split into beginner, intermediate and advanced tiers, plus real past contest tasks to practice on.

## Why this exists
 
Good AI resources are scattered across YouTube, Kaggle, GitHub, and course sites. This project pulls the useful ones into one clean, tiered roadmap so students prepping for IOAI don't have to go hunting.

## Contributing
 
Found a resource that helped you understand something on the syllabus? **Please add it.** This project only gets better with more people contributing what actually worked for them.
 
See [CONTRIBUTING.md](./CONTRIBUTING.md) for how to submit a resource. In short:
 
1. Open a pull request adding your resource to the `DATA` array in the HTML file.
2. Include a short description and the correct tier (Beginner / Intermediate / Advanced).
3. We review PRs within **2–3 days**.
## Disclaimer
 
We don't promote, endorse, or profit from any of the linked resources — they're shared purely to help students learn with a clean, structured roadmap.
